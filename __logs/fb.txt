Vấn đề là bạn đang tạo một **Extension** nhưng lại cần một **Mark**. TextStyle trong Tiptap là một Mark, không phải Extension.

## **Giải pháp: Sử dụng đúng các extension có sẵn**

Thay vì tạo custom extension phức tạp, hãy sử dụng các extension chính thức từ Tiptap:Giờ tôi hiểu rõ vấn đề rồi! Đây là cách đúng để implement:

## **Giải pháp đơn giản: Dùng các extension chính thức**

Bạn **KHÔNG cần** tạo custom extension phức tạp. Chỉ cần sử dụng các extension có sẵn:

```typescript
// Trong file editor config của bạn
import { useEditor } from '@tiptap/react';
import StarterKit from '@tiptap/starter-kit';
import Underline from '@tiptap/extension-underline';
import TextStyle from '@tiptap/extension-text-style';
import { Color } from '@tiptap/extension-color';
import { FontSize } from '@tiptap/extension-font-size'; // Nếu có package này

const editor = useEditor({
  extensions: [
    StarterKit,
    Underline,
    TextStyle, // Đây là Mark, không phải Extension
    Color,     // Extends TextStyle
    // FontSize nếu có
  ],
  // ... other config
});
```

## **Nếu cần custom FontSize (vì không có package chính thức)**

Tạo một **Extension** để add attribute vào TextStyle **Mark** có sẵn:

```typescript
import { Extension } from '@tiptap/core';

export const FontSize = Extension.create({
  name: 'fontSize',

  addOptions() {
    return {
      types: ['textStyle'],
    };
  },

  addGlobalAttributes() {
    return [
      {
        types: this.options.types,
        attributes: {
          fontSize: {
            default: null,
            parseHTML: element => element.style.fontSize || null,
            renderHTML: attributes => {
              if (!attributes.fontSize) {
                return {};
              }
              return {
                style: `font-size: ${attributes.fontSize}`,
              };
            },
          },
        },
      },
    ];
  },

  addCommands() {
    return {
      setFontSize: (fontSize: string) => ({ chain }) => {
        return chain().setMark('textStyle', { fontSize }).run();
      },
      unsetFontSize: () => ({ chain }) => {
        return chain().setMark('textStyle', { fontSize: null }).run();
      },
    };
  },
});
```

## **Cấu trúc đúng trong editor:**

```typescript
import { useEditor } from '@tiptap/react';
import StarterKit from '@tiptap/starter-kit';
import Underline from '@tiptap/extension-underline';
import TextStyle from '@tiptap/extension-text-style';
import { Color } from '@tiptap/extension-color';
import { FontSize } from './extensions/FontSize'; // Custom extension của bạn

const editor = useEditor({
  extensions: [
    StarterKit,
    Underline,
    TextStyle,  // MARK - phải có trước
    Color,      // Extension adds attribute to TextStyle mark
    FontSize,   // Extension adds attribute to TextStyle mark
  ],
  editorProps: {
    transformPastedHTML(html) {
      // Xử lý paste để remove color
      const div = document.createElement('div');
      div.innerHTML = html;
      
      div.querySelectorAll('[style]').forEach((el) => {
        const style = el.getAttribute('style');
        if (style) {
          const newStyle = style
            .split(';')
            .filter(prop => {
              const trimmed = prop.trim().toLowerCase();
              return !trimmed.startsWith('color:') && 
                     !trimmed.startsWith('background-color:');
            })
            .join(';');
          
          if (newStyle) {
            el.setAttribute('style', newStyle);
          } else {
            el.removeAttribute('style');
          }
        }
      });
      
      return div.innerHTML;
    }
  },
  content: '<p>Your content here</p>',
});
```

## **Tại sao error "no mark type named 'textStyle'"?**

Vì bạn đang tạo một `Extension.create()` với name là `'textStyle'`, nhưng Tiptap cần một **Mark** (dùng `Mark.create()`), không phải Extension. TextStyle là một mark renders thẻ span và cho phép thêm styling attributes.

**Giải pháp:** Import `TextStyle` mark chính thức và dùng `Extension` để add attributes vào nó thông qua `addGlobalAttributes()`.
